¿La fuente dice realmente eso?

Un error frecuente: citar una fuente que no respalda lo que afirmas. Ocurre sobre todo cuando una IA sugiere referencias que nadie llegó a comprobar. Pega la afirmación y el texto de la fuente.

Resultado

Orientativo, no es una nota. Compara palabras clave, no entiende el sentido: una fuente puede usar otras palabras para decir lo mismo, o las mismas para decir lo contrario. Léela siempre antes de citarla.
